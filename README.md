# Laku's Uno
Requires Python 3. Run `python server.py` and open http://localhost:8000 in two browser tabs to test. For remote play, deploy this folder to a Python web host with the start command `python server.py`, then share the public HTTPS URL or room invite. The server honors PORT. Use a single server instance. No external dependencies. Rooms are in memory and reset on restart. This prototype uses polling, simplified draw-and-pass rules, mandatory UNO before the last card, no challenge system, no reconnect or rematch, and no production authentication or abuse protection. Do not expose it as a production service without hardening.
